# Machine Learning - IIT KGP (2025)

This repository contains lecture's slides, assignments resources for the Machine Learning course at IIT Kharagpur.

## 📂 Folder Structure

- `Assignments/`
- `Slides/`

## 🧠 Topics Covered

1. `01-Introduction.pdf` – Course overview, basics of ML
2. `02-linear-models.pdf` – Linear Regression, Logistic Regression
3. `03-svm.pdf` – Support Vector Machines
4. `04-probabilistic-models.pdf` – Bayesian inference, Naive Bayes
5. `05-DT-Ensemble.pdf` – Decision Trees and Ensemble Methods
6. `06-boosting-XGboost.pdf` – Boosting techniques, XGBoost
7. `07-crossvalidation.pdf` – Cross-validation strategies
8. `08-clustering.pdf` – K-Means, Hierarchical Clustering
9. `09-graphical-models.pdf` – Bayesian Networks, Markov Models
10. `10-NN.pdf` – Feedforward Neural Networks
11. `11-RNN-Attention-transformers.pdf` – RNNs, Attention, Transformers
